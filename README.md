# Logistics KPI Dashboard

An executive-facing analytics dashboard tracking 6 logistics KPIs across 8 regions using the Brazilian E-Commerce (Olist) dataset.
SQL queries aggregate 100K+ order records; results are visualized in Tableau.

## 6 KPIs Tracked

1. On-Time Delivery Rate: Percent of orders delivered on or before estimated date
2. Avg Delivery Time: Days from purchase to delivery
3. Avg Fulfillment Cost: Average freight cost per order
4. Cancellation Rate: Percent of orders canceled
5. Customer Satisfaction: Average review score (1–5)
6. Avg Revenue per Order: Total payment value / order count
